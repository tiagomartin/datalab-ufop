# Fotografias locais (opcional)

Para funcionamento 100% offline, coloque aqui 49 fotografias WebP, com os nomes definidos na constante `PHOTO_SLUGS` de `../app.js` (ex.: `leao.webp`, `onca-pintada.webp`). Use imagens licenciadas para redistribuição, mantenha a atribuição e a licença de cada fotografia.

Sem fotos locais, o jogo tenta obter uma miniatura da Wikipédia quando há conexão à internet. Se a consulta falhar, apresenta uma ilustração por emoji. As fotos nunca são mostradas antes da revelação do animal.
